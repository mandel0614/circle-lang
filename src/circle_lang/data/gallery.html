VIRTUAL CELL PROGRAMMING

Circle

Write a behavior. Inspect its execution.

A first language release that connects declarative specifications to executable virtual cell behaviors, from internal states to moving and interacting populations.

0.1.0rc1 · Local release candidate

Each report contains the Circle source, recorded execution, empirical contract checks, and reproducibility metadata. Use Play or the time slider to inspect the first seed.
